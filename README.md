# Lead Finder AI 🚀
An AI agent that analyzes social media messages (Telegram, Instagram, LinkedIn) to filter spam, score leads, and draft personalized responses.

## Tech Stack
- **Backend:** FastAPI, Python, SQLite
- **AI/LLM:** LangGraph, AvalAI
- **Infrastructure:** Ubuntu, Nginx, Systemd
- **Security:** In-memory Rate Limiting (slowapi)
